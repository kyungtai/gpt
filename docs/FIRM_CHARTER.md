# Claude Capital — 펌 헌장 (Paper)

AI가 운영하는 글로벌 멀티전략 프랍 트레이딩 펌의 운영 원칙입니다.
**현재 단계: 합성 시장 + 페이퍼 트레이딩 전용.** 실주문 경로는 코드에 존재하지 않습니다.

## 1. 조직

| 역할 | 담당 | 코드 |

| CEO / CIO | Claude: 자본 배분, 데스크 신설·폐쇄, 한도 승인 | `propfirm/allocator.py`, `docs/operations/` |

| 오너 / 이사회 | 사용자: 실자금·실주문 전환 등 최종 승인권 | — |

## 3. 자본 배분 (CIO)

- 펌 목표 변동성: 자본의 **10%/년**
- 21영업일마다 재배분. 데스크 손익을 예산 단위로 정규화한 뒤
  126일 샤프로 지수 가중 (η=0.35) → 비중 5%~35% → 수축 상관행렬로 사전 펌 변동성을 목표에 맞춤
- 데스크 예산 합은 펌 예산의 3배를 넘지 않음 (분산효과 과신 방지)

## 4. 리스크 한도 (CRO)

| 범위 | 트리거 | 조치 |
|---|---|---|
| 데스크 | 일간 손실 > 4 × 일간 예산 | 즉시 플랫, 5일 정지 |
| 데스크 | 드로다운 > 1.25 × 연간 예산 | 21일 정지 → 63일간 50% 예산 근신 |
| 데스크 | 그로스 명목 한도 (CTA 3x, STATARB 4x, DELTA1 12x, RV 10x) | 비례 축소 |
| 데스크 | 사전 스트레스 손실 > 자본의 1.5% (VOL: 기초자산 동시 10% 갭) | 비례 축소 |
| 펌 | 사전 99% 1일 VaR > 자본의 2% | 전 데스크 비례 축소 |
| 펌 | 그로스 > 20x | 전 데스크 비례 축소 |
| 펌 | 고점 대비 -6% | 디리스크: 전 데스크 50% |
| 펌 | 고점 대비 -10% | **킬스위치**: 전 포지션 청산, 10일 정지 → 사후 리뷰 → 21일 25% 리스크 → 50% |
| 펌 | 디리스크 중 낙폭 < 3% | 정상 복귀 |

리스크 엔진의 결정은 CIO 배분보다 우선하며, 데스크가 무시할 수 없습니다.

## 5. 실거래 전환 게이트

아래를 **모두** 충족하고 오너가 명시적으로 별도 지시하기 전에는 실주문 코드를 추가하지 않습니다.

1. 실제 과거 시장 데이터(합성 아님)로 데스크별 워크포워드 검증, 거래비용·슬리피지 실측치 반영
2. 최소 3개월 실시간 데이터 기반 페이퍼 트레이딩, 시뮬레이션 대비 괴리 분석
3. 주문 전 하드 리밋 (주문당 수량/명목, 가격 밴드, 초당 주문 수), 수동 킬스위치, 포지션 대사
4. 브로커/거래소 인증 정보는 비밀 관리자에만 보관 (저장소 커밋 금지)
5. 소액 한도로 시작하는 단계적 증액 계획을 오너가 승인

## 6. 운영 주기

- 일간: 마킹 → 리스크 점검 → 목표 포지션 → 체결 → 리포트 (`python -m propfirm run`)
- 월간: CIO 재배분, 운영 메모 (`docs/operations/`)
- 분기: 시나리오 분포 점검 (`python -m propfirm scenarios`), 데스크 존폐·한도 재검토
